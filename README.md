# Console Calculator (C#)

A lightweight, terminal-based calculator application built with C#. This program allows users to perform fundamental arithmetic operations through a simple interactive menu.

### 🚀 Features
Four Basic Operations: Supports Addition, Subtraction, Multiplication, and Division.

Error Handling: Includes a check to prevent division by zero.

User-Friendly Interface: Clear menu-driven navigation using numeric inputs.

Double Precision: Uses double data types to handle both integers and floating-point numbers.

### 🛠️ How It Works
Menu Selection: The user is presented with four numbered options.

Input Collection: The program prompts for two numbers.

Operation Logic: A switch statement processes the choice and calculates the result.

Output: The final result is printed directly to the console.

### 📋 Arithmetic Operations
Option	Operation	Symbol
1	Addition	+
2	Subtraction	-
3	Multiplication	*
4	Division	/
